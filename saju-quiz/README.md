# 사주팔자 - 운명을 알아보는 웹사이트

점신(https://www.jeomsin.co.kr/)을 벤치마킹한 사주팔자 보기 사이트입니다.

## 기능

- 🎂 생년월일시 입력
- 📊 사주팔자 계산 (년주, 월주, 일주, 시주)
- 🔮 오행(五行) 분석
- 💼 직업운 분석
- 💰 재물운 분석
- ❤️ 애정운 분석
- 🏥 건강운 분석
- 🎯 종합 운세 및 조언

## 사용 방법

### 로컬에서 실행

1. 이 폴더에서 간단한 HTTP 서버 실행:
   ```bash
   cd sajupalza
   python3 -m http.server 8000
   ```
   
   또는 Node.js를 사용한다면:
   ```bash
   npx http-server -p 8000
   ```

2. 브라우저에서 접속:
   ```
   http://localhost:8000
   ```

### 배포

정적 웹사이트이므로 다음 플랫폼에 무료로 배포 가능:
- GitHub Pages
- Vercel

- Cloudflare Pages
