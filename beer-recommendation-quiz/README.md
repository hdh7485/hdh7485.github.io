# 맥주 추천 테스트 🍺

당신의 취향에 맞는 완벽한 맥주를 찾아드립니다!

## 테스트 방법

1. 12개의 질문에 솔직하게 답변하세요
2. 맛 선호도, 향, 상황 등을 종합적으로 분석합니다
3. 6가지 맥주 스타일 중 가장 잘 맞는 것을 추천받습니다
4. 구체적인 맥주 브랜드도 함께 추천해드립니다

## 추천 맥주 스타일

- **라거 (Lager)** - 가볍고 청량한 맛
- **페일 에일 (Pale Ale)** - 균형잡힌 풍미
- **IPA (India Pale Ale)** - 강한 홉 향과 쓴맛
- **스타우트 (Stout)** - 진하고 묵직한 맛
- **밀맥주 (Wheat Beer)** - 부드럽고 과일향
- **필스너 (Pilsner)** - 깔끔하고 드라이한 맛

## 특징

- 취향 기반 정확한 추천
- 각 스타일별 특성 상세 설명
- 구체적인 맥주 브랜드 추천
- 추천 상황 및 페어링 정보 제공

## 기술 스택

- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- Vanilla JavaScript
