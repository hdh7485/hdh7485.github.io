# 점심 메뉴 룰렛 🍽️

오늘 점심 뭐 먹지? 고민 끝!

## 기능

- **200개의 다양한 메뉴**: 한식, 중식, 일식, 양식, 분식, 아시안, 멕시칸 등
- **랜덤 선택**: 버튼 하나로 메뉴 자동 선택
- **룰렛 애니메이션**: 2초간 돌아가는 재미있는 효과
- **오늘의 통계**: 오늘 몇 번이나 메뉴를 뽑았는지 확인
- **전체 메뉴 보기**: 어떤 메뉴들이 있는지 한눈에

## 메뉴 구성

- 한식 40개 (김치찌개, 된장찌개, 불고기, 비빔밥, 삼겹살, 갈비탕, 감자탕 등)
- 중식 25개 (짜장면, 짬뽕, 탕수육, 마라탕, 훠궈, 마파두부 등)
- 일식 30개 (초밥, 라멘, 우동, 카레, 돈부리, 덴뿌라 등)
- 양식 30개 (파스타, 피자, 햄버거, 스테이크, 리조또 등)
- 분식 20개 (떡볶이, 김밥, 라면, 만두, 튀김 등)
- 치킨/야식 15개 (후라이드, 양념, 간장, 파닭, 치즈치킨 등)
- 동남아/아시안 20개 (쌀국수, 팟타이, 똠얌꿍, 커리, 락사 등)
- 멕시칸 10개 (타코, 부리또, 퀘사디아, 나초 등)
- 패스트푸드 10개 (핫도그, 감자튀김, 너겟, 토스트 등)

## 사용법

1. "메뉴 뽑기!" 버튼 클릭
2. 2초간 룰렛이 돌아감
3. 최종 메뉴 확인!
4. 마음에 안 들면 "다시 뽑기!" 버튼으로 재시도

## 기술 스택

- HTML5
- CSS3 (Animations, Gradients)
- Vanilla JavaScript
- LocalStorage (오늘의 카운트 저장)
