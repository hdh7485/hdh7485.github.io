# F1 리액션 테스트 🏎️

F1 레이스 스타트를 재현한 반응 속도 테스트입니다.

## 테스트 방법

1. 5개의 빨간 불이 하나씩 켜집니다 (실제 F1 스타트 라이트 방식)
2. 모든 불이 켜진 후 랜덤 딜레이가 있습니다
3. 불이 모두 꺼지는 순간 최대한 빠르게 클릭하세요!
4. 총 5번의 시도 후 평균 반응 속도를 계산합니다
5. F1 드라이버들의 평균 반응 속도와 비교해보세요

## 참고 사항

- F1 드라이버 평균: 0.2초 ~ 0.3초
- 최고 수준: 0.15초 이하
- 일반인 평균: 0.25초 ~ 0.35초

## False Start

너무 일찍 클릭하면 실격(False Start)됩니다. 
실제 F1에서도 스타트 라이트가 꺼지기 전에 출발하면 페널티를 받습니다!

## 기술 스택

- HTML5
- CSS3 (Flexbox, Gradients, Animations)
- Vanilla JavaScript
